# 🍓 Berry Quest

A cute mini browser game made with **HTML, CSS and vanilla JavaScript**.

## 🎮 How to play

- **← / →** Move the Berry Cat
- **↑ / Space** Jump
- Collect strawberries for points
- Golden strawberries give **+50**
- Avoid the snail 🐌 and bee 🐝, or jump on them to smash them for +25 points
- You have **3 lives**
- Try to beat your saved high score 🏆

## ✨ Features

- Cute retro/pixel-inspired UI
- Score system
- High-score saved with localStorage
- 3-life system
- Collectibles
- Golden collectible
- Multiple enemies
- Jump mechanic
- Keyboard controls
- Mobile touch controls
- Simple sound effects
- Responsive layout
- No external libraries
