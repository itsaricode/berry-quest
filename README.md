
# 🍓 Berry Quest

A cute little pixel-inspired strawberry collecting game built with **HTML, CSS, and JavaScript**!

Collect strawberries, avoid enemies, beat your high score, and enjoy a little retro gaming adventure. 🎮💗

## 🎮 Live Demo

🍓 **Play Berry Quest:** [Play the Game](https://itsaricode.github.io/berry-quest/)

## ✨ Features

- 🍓 Collect strawberries to earn points
- ✨ Golden strawberries for bonus points
- 🐌 Snail and 🐝 bee enemies
- ❤️ Three lives per game
- 🏆 Best-score tracking with local storage
- 🔊 Sound effects with a toggle button
- 🎀 Cute pastel and pixel-inspired game design
- 🔄 Start and Play Again functionality

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 Run Locally

1. Clone this repository:

   ```bash
 
   https://github.com/itsaricode/berry-quest.git
   
   ```

2. Open the project folder.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
